# FRB Launch — ぐりぐりレール改修（2026-11-15）

## ベース
`launch_app_20261115_223904.zip`（22:39版）。前回の差分を別途再適用する必要はありません。

## 修正点
1. **右クリックメニュー二重表示の防止**
   - `remote_context_menu()` で最初に生成したExp/List実メニューを認識して再利用し、予備メニューを無条件に追加表示しない。
   - 新規メニューを開く前に既存メニューを閉じる。
   - 丸レールのWindowsネイティブ `contextMenuEvent` を受理し、右ボタンrelease処理と競合させない。
   - メニュー管理参照を一意に保持し、非モーダルメニューの居残りを防止する。
2. **丸いぐりぐりを52→60pxへ拡大**
   - Exp/List境界から左へ6px寄せ、Listアイコンに被る幅を増やさない。
   - 文字と中央の縦点線を60px用に再配置。
   - 本体子Widgetなので親移動・画面サイズ変更・Exp幅変更への追従は継続。
3. **Exp側のシングルクリックで開閉トグル**
   - 丸レールのExp側だけ、展開済みフォルダーは折りたたむ。
   - 未展開時には既存のExpクリック処理を実行して展開する。
   - 別Window/1.5列リモコン側の従来仕様は変更しない。
4. **メニュー表示中の丸レール認識**
   - 既存のコンテキストメニューホイール制御で、独立Remoteだけでなく埋め込みレールも操作面として扱う。
   - メニュー外クリックの自動終了と丸レール内のホイール操作を整合させる。

## 実機で確認してほしいこと
- 丸レールの右クリックを1回：メニューは1つだけ。
- メニュー外の空白をクリック：確実に閉じる。Launchを移動しても古いメニューが残らない。
- 丸レールの左半分をクリック：選択中のExpフォルダーが展開・折りたたみを交互に繰り返す。
- 右半分のクリック・上下ぐりぐり、Exp側ダブルクリックの自動移動ON/OFFが従来どおり。
- Exp幅を変えても、60px円が境界に追従しList先頭アイコンと重ならない。
- リモコンウィンドウの従来クリック動作が変わらない。
