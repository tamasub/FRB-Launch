# FRB Launch 小物改善 5件（2026-11-19）

適用基準: `launch_app_20261119_213701.zip`。
このZIPは**差分ファイルのみ**です。適用前に既存フォルダーをバックアップしてください。

## 変更内容

1. **ぐりぐりリモコンの誤ダブルクリック**：丸い子ウィジェットの透過属性を解除。さらに下のExp/Listツリーへ誤配送されたマウス押下・開放・ダブルクリックを、丸の領域内に限り遮断します。元のリモコン操作（ホイール・クリック・長押し等）は維持。
2. **Exp KeyboardのEnter**：`/` メニューで物理フォルダー・仮想フォルダー・（カレントフォルダー）にEnterすると、Files Listでその場所を表示します。右矢印は階層展開だけです。
3. **重複メニューの整理**：`/` のフォルダー用コンテキストメニューから「Filesリスト」の項目だけを非表示。通常のExpコンテキストメニューは変更しません。
4. **Exp Keyboardの行密度**：「三」ボタンのFiles List表示密度と共通化。コンパクト27px／標準37pxを使用。Launchウィンドウの高さに応じたメニュー行高変化を取り除き、メニューのスクロール可能範囲は画面の高さから決めます。
5. **第3列の📂**：Browserを除くエディタ表示ヘッダー左端にボタンを追加。Launch経由で**正常に開いたファイルの親フォルダー**を、クリックしたときだけFiles Listへ表示します。1候補なら直接移動、複数の異なる親フォルダーがあれば選択メニュー。開いた瞬間のFiles Listの位置は**一切変えません**。履歴はエディタ別・セッション中だけ保持します。

## 意図的に対応していないこと

- 外部エディタの内部で、Launchを通さず開いたファイルのタブやアクティブパスは収集しません。
- 「ファイルを開くたびFiles Listを自動移動する」Optionは**将来の検討候補**で、今回は追加していません。
- 外部エディタのウィンドウの収容・外出し方式、最小化・終了、VS Code固定プロファイルは変更していません。

## 確認項目（Windows実機）

- リモコンがExp行に重なる状態で、円の左／右／中心をクリック・ダブルクリック・ホイール操作。下の行が勝手に開かないこと。
- `/` → フォルダーで右矢印は展開、EnterはFiles Listへ移動。（カレントフォルダー）も同様。
- `/` のコンテキストメニューだけ「Filesリスト」が出ないこと。通常Expメニューは従来どおり。
- 「三」の表示密度を切替後、`/` の第1・第2階層メニューの間隔が変わること。Launchの高さを変えても密度は一定であること。
- Files ListをフォルダーAに表示したまま `/` からフォルダーBのTXTやJSON/Markdownを開く → Files ListはAのまま。第3列の📂 → Bを開く。
- 同じエディタで別々の親フォルダーのファイルを2つ開く → 📂で2候補から選択できること。Browserには📂を表示しないこと。
