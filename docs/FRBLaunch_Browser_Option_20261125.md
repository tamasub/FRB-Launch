# FRB Launch — 内部ブラウザー利用設定（2026-11-25）

## 背景・責務
会社の認証環境では第3列の組み込みブラウザーを利用しにくい。URL起動の既定経路を切り替えられるようにし、組み込みブラウザーの構築・先行起動を外部モードで禁止する。

## 変更内容
- Launch所有の `defs/launch/options/webview_settings_view_def_v0_1.json` 先頭に既存の `mode` を公開。`embedded`=有効、`external`=無効。追加のUser設定ファイルや独自の編集画面は作らない。
- `remember_login` と `new_tab_url` に既存のGeneric Editorの `visibleWhen` 形式を適用。有効時のみ表示。既存の保存方式（非表示値保持）を変更しない。
- 初期値は従来どおり `embedded`。保存後にLaunchを完全終了し再起動する。実行中のブラウザー破棄やタブの移し替えはしない。
- 無効時、明示的ブラウザー指定のないHTTP(S) Openは従来のWindows関連付け（`os.startfile`）に委ねる。既存の明示的Chrome/Edge/Profile指定、取り込んだブックマークの元ブラウザー・プロファイルは保持する。Run、ファイル起動等は変更しない。
- 外部モードでは第3列ネットワークブラウザーの初期化・生成・表示の入口をガードする。既存のFiles/エディターをブラウザーのために切り替えない。
- RemoteのBrowser左クリックは無効の案内、右クリックからのブックマーク利用は維持。外部モードでは新規/カレントタブの選択を表示しない。
- ファイル検索設定の合成失敗によって正常なブラウザー設定まで標準に戻らないよう、読み込みを分離。ブラウザー設定自体の合成失敗時は従来どおり警告してSystem標準にフォールバックする。
- Generic Editor（オプション設定）のローカルWebEngineはネットワークブラウザーとは別責務で、変更しない。QtWebEngineの依存関係も残す。

## 適用・確認
1. Launchを完全終了し、差分ZIPをソースルートに上書き。
2. 既存のPython 3.15環境で `_build_windows.bat` を実行（ソース起動ならビルド不要）。Studio側の差分は不要。既存のStudio Family Generic Editorを使用する。
3. オプション設定 → ブラウザーで先頭の「Launch内部ブラウザーを利用する（再起動後に反映）」を無効にする。詳細2項目が非表示になること。
4. 保存して確定し、Launchを完全終了（タスクトレイから終了）、再起動。
5. 明示的なブラウザー指定のないURLをメニュー、ファイル一覧の登録項目、検索結果から起動。Windows既定ブラウザーで開き、第3列ブラウザーが開かないこと。Remote右クリックのブックマークも確認する。ブラウザーを指定した項目は従来の指定先で開くこと。
6. 有効に戻して保存・再起動。既存のログイン記憶・新規タブURLが残り、内部ブラウザーが従来どおり動作すること。

## 検証
Linux / Python 3.13.5で、新規のQt非依存契約テスト12件PASS。関連8テストファイルを含む計57件の実行結果は51 PASS / 5 FAIL / 1 SKIP。変更前の同じ関連8ファイルは38 PASS / 6 FAIL / 1 SKIP。修正後の5 FAILは変更前から存在（古いテストダブル・ソース期待値4件、添付ZIPに含まれないconfig/frb_launch_data.json依存1件）。旧テストのうち変更した契約（公開フィールド追加・外部モードのFiles保持・テストダブルへの設定追加）は更新済み。StudioのNode合成実装がZIPに含まれないため、合成テスト1件はスキップ。Windows GUI上の条件表示、非表示値の保存・再表示、実際のOS起動・認証、Python 3.15 EXEビルドは未実施。インデックスの重さとCommanderの問題は別途扱う。
