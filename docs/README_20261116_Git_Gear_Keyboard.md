# FRB Launch 差分 — 設定メニューキー操作 / Gitコミット先ぐりぐり

## 基準

`launch_app_20261116_221858.zip` のプロジェクトルートへ**同名パスで上書き展開**してください。設定JSONは変更しません。差分は src の3ファイル、tests の1ファイルです。

## ① 歯車の設定コンテキストメニュー

- 歯車クリック、`Ctrl+I` のどちらで開いても、従来の `RemoteContextWheel` と同じキー操作を利用します。
- `↑/↓`: 項目移動、`→`: サブメニューへ入る、`←`: 親へ戻る／最上位で閉じる、`Enter`: 選択／実行、`Esc`: 閉じる。
- メニューを新設せず既存QActionを実行します。ぐりぐりとマウス操作は既存エンジンを維持します。

## ② Gitコミット先選択ダイアログ

- 初期表示時のフォーカスは `コミット先リポジトリ` に置きます。毎回先頭の「選択してください...」から開始します（推測による自動選択なし）。
- Gitダイアログ上、またはFRB Launch自身の領域上でホイール・ぐりぐりを回すと、実在するリポジトリ候補を循環選択します。ホイール位置をコミット先コンボ上に固定する必要はありません。
- ダイアログの**余白**、またはLaunch本体のボタン・項目以外など（ガードされる背景領域）で一度左クリックすると「OK／Cancel選択モード」へ移ります。これはボタンへのフォーカス移動であり、**コミット実行ではありません**。
- 以後のホイール・ぐりぐりは `OK`／`Cancel` の選択になります。ボタンの実クリック、またはぐりぐり中央クリックで確定してください。
- コンボを再クリックすると「コミット先選択モード」に戻せます。
- メッセージ欄のクリック・文字編集、リポジトリのドロップダウン選択、実ボタンクリックはネイティブ操作を維持。
- 安全策：背景クリックではコミットしない／先頭ヒントをリポジトリとして選ばない／ボタン選択開始はCancel／既存のGitプレビュー＆確認ダイアログ維持。

## 実機確認

1. 歯車クリック→`↓`→`→`で設定サブメニュー表示、`←`で戻る、`Enter`選択、`Esc`終了。
2. `Ctrl+I`からも同じ上下左右操作とぐりぐり操作。
3. Gitコミット画面表示直後、List上でぐりぐり→コミット先が変わる。コンボ直上でも変わる。未選択時OKは既存の検証が働く。
4. 余白クリック→Cancelにフォーカス→ぐりぐりでOKへ。余白をクリックしても勝手にコミットされない。
5. もう一度コンボをクリック→コミット先選択へ戻る。メッセージの日本語編集・Cancel・確認画面が従来どおり。
