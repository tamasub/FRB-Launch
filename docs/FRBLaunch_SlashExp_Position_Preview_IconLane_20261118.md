# FRB Launch `/` 矢印ナビ 調整（2026-11-18）

## 基準と範囲

- 基準：`launch_app_20261118_140140.zip`（ユーザー添付版）
- 差分：`src/app.py`、`src/slash_exp_navigation.py`、`tests/test_slash_exp_navigation_20261118.py`、本変更記録
- 通常の Files Exp／Files List のモデル・設定JSON・既存実行器には変更を加えない。

## 変更内容

1. **長いメニューの位置固定**：子メニューを最初に表示した位置で固定。Qt ネイティブスクロール中の意図しないウィンドウ移動は `moveEvent` から元の位置へ復元し、上下矢印での選択は維持する。ルートメニューにも同じ固定処理を適用する。
2. **`/` 直後の縦位置**：丸いぐりぐりボタンの高さではなく、表示中の Files Exp ツリーの先頭行付近を基準とする。横位置は従来のぐりぐりボタン右側を維持。見えている Exp がない場合は従来の位置へフォールバックする。
3. **URL の第3列プレビュー**：仮想ファイル末端で Enter した際、Files List のダブルクリックが使用する `preview_bookmark_from_list()` を先に呼ぶ。既存のURL検証・埋め込みブラウザー条件が成立すれば Files 第3列に表示。対象外の通常コマンドや外部ブラウザーモードでは従来の `activate_virtual_launch_item()` に戻す。`→` は従来どおりコンテキストメニュー表示のみ。
4. **アイコン位置を揃える**：Exp の Page タイトルに埋め込まれている先頭絵文字（`💼 My Work` など）を、`/` メニュー表示時だけQIconとして描画。フォルダー／ファイルと同じアイコン列に配置。元のデータ・検索文字列は変更しない。先頭アイコンが存在しない通常行は従来どおり左寄せ。

## 操作条件（維持）

- `↑↓` 同じ列内での選択移動のみ / `→` 下位階層、末端ではコンテキストメニュー表示 / `←` 一段戻る
- 中間階層の Enter は実行不可 / 末端 Enter は実行 / コンテキストの最終 Enter は操作確定
- `/` 再入力・Esc は閉じる / 各列検索・長文省略・Launch高さ約70%という既存制約を維持

## テストと注意点

- 新UIの振る舞いテスト：25件PASS（位置復元、起点のY座標、絵文字アイコン、URLプレビュー優先・通常コマンドへのフォールバックを追加）
- 周辺を含むテスト：64件PASS、2件SKIP、5件FAIL。FAILは基準ZIPでも同じ5件が発生（未同梱の個人設定JSON、PySide6未導入など）。
- Windows実機ではPySide6のネイティブメニューの移動・スクロール・絵文字描画を確認できていないため、実画面での確認を要する。
