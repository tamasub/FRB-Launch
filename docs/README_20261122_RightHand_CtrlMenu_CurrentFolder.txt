■ 実装
1. Ctrl + Windowsメニューキー（アプリケーションキー）でLaunch全体のアクションメニューを開きます。
   ↑↓ で選択、Enter/テンキー0で実行、Escで閉じます。
   初期選択は先頭の有効メニューです。
   メニュー項目（固定4件、今回JSONカスタマイズは対象外）:
   - Launch検索履歴を表示 → 既存の検索履歴ポップアップを直接表示
   - パンくず履歴を表示 → 既存Ctrl+Gの処理（Files画面のみ）
   - フォルダ検索履歴を表示 → 既存Ctrl+Hの処理（Files画面のみ）
   - 設定を表示 → 既存Ctrl+Iと同じ設定メニュー
   ※Ctrl+Fは従来の検索欄フォーカス動作のままです。
   ※通常のWindowsメニューキーは従来どおり / ナビゲーション。
   ※ショートカット擬似送信ではなく既存処理の直接呼び出しです。
2. Files Listで設定JSONのPage（例: Windows）を開いた際も、
   先頭に「（カレントフォルダー）」行が表示されるよう修正しました。
   同行を選んで → を押すと既存のLaunch JSON管理メニューが開き、
   「Exp列へ戻る」「カテゴリーフォルダーを作成...」等にアクセスできます。
   既存の物理フォルダー・JSONサブフォルダーは従来どおり。

■ 適用
1. FRB Launchを完全終了（タスクトレイ常駐分も終了）。
2. Launchフォルダーのバックアップを取得。
3. ZIP内の src/ と tests/ を現行Launchフォルダーへ上書き展開。
4. _run_windows.bat 等、普段の起動方法で起動。
   ※exe版を使用中の場合、Pythonソースの変更だけでは反映されません。exe再ビルドが必要です。
