# FRB Launch — パンくずとExpの分離（2026-11-21）

基準資材：`launch_app_20261121_195147.zip`

## 決定済みの動作

- `defaults/state.ini` の `[General]` に `exp_auto_expand=false` を追加（新規配布時の正）。
- 既存の `%LOCALAPPDATA%\FRBLaunch\state.ini` にこの項目がなくても**新標準のfalse**で動く。既存ファイルを勝手に書き換えない。
- `exp_auto_expand=false`: Listでフォルダーを選択・Enter・ダブルクリック・パンくず移動しても、Expツリーの展開、閉じる操作、選択行、スクロールは勝手に変更しない。
- `exp_auto_expand=true`: 従来のパンくず追従・自動展開・上位移動時の枝折り畳みを維持する。
- List→Expへキーで操作対象を移す場合（`←`）は、新標準では**既に開いている範囲の最深の祖先**を選択する。枝は開かない。
- 新標準でExpの三角（▶/▼）を手動操作した場合はパンくずを移動しない。パンくずに至る経路上の枝を開いたら、いま見えている最深の祖先へExpのカレントを移し、**Expの緑枠＋緑背景**を表示する。関係ない枝の展開ではその枝を選択したままにする。
- Expの行そのものの通常クリックによるフォルダー移動は従来どおり。

## コンテキストメニュー

List側のフォルダー行、現在フォルダーの背景・空白領域のメニューに、`最新の情報に更新` の直下へ **パンくずまでExpを展開** を追加。

- パンくずの現在地に至る必要な祖先だけをExpで展開する。
- Expの現在地行へスクロールし、緑枠＋緑背景の操作対象とキーボードフォーカスをExpへ移す。
- Listとパンくずの現在地を変更しない。
- `exp_auto_expand` がtrueでもfalseでも、この**明示操作**は一括展開する。
- Exp自身の右クリックメニューや検索結果メニューにはこのコマンドを表示しない。
