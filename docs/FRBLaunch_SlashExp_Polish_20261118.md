# FRB Launch / 矢印ナビ 改修差分（2026-11-18）

対象基準: `launch_app_20261118_124657.zip`

## 目的

`/` キーで Exp 第1階層から矢印主体のナビゲーションを行う。通常の Exp／Files List の実行ロジックは再利用し、移動と実行を分離する。

## 変更点

- デスクトップから起動直後でも `/` が押せるようアプリ内ショートカットを追加。既存の検索入力欄や編集欄では `/` を文字として使えるよう、フォーカスに応じて有効状態を制御。
- `/` を再度押すと、開いている `/` ナビを閉じる（検索欄やコンテキストメニューからも終了可能）。
- `↑↓` は同じ列のカレント変更のみ、`→` は次の階層、`←` は前の階層。途中の `Enter` は無効、末端の `Enter` のみ既存実行処理へ渡す。
- 末端の `→` は通常の Exp／Files List コンテキストメニューを次の列として開く。ルートメニューを先に閉じて別座標へ表示する旧処理を撤去。
- 各階層の上部に検索欄を設置。文字入力／Backspace はカレント列だけをフィルタ。IMEイベントもその列へ転送。
- 項目アイコンは通常の Qt 左側アイコン領域に配置。`▶` を文字列に加えず、子階層を持つ項目だけ右端に小さな矢印を描画。末端には常時表示しない。
- メニュー縦幅を Launch 本体の高さの約70%までに制限。長いリストは Qt のメニュースクロール方式を使う。
- 初回 `/` 表示位置を「ぐりぐりボタン右側＋約14px」に配置。
- 実行アイテム（ZIP等）は既存 JSON 仮想ツリーに含まれるものを使い、実行は既存の `activate_virtual_launch_item`／`navigate_virtual_launch_folder`／`navigate_files_exp_folder` へ委譲。

## 操作契約

| 操作 | 中間階層 | 末端階層 | コンテキストメニュー |
|---|---|---|---|
| ↑↓ | カレント移動のみ | カレント移動のみ | 既存アクション選択 |
| → | 子階層を開く | コンテキストメニューを開く | サブメニューがあれば開く |
| ← | 一段戻る | 一段戻る | 前の列に戻る |
| Enter | 無効 | 既存 List と同等の実行 | 選択アクションを実行 |
| / | 全部閉じる | 全部閉じる | 全部閉じる |
| Esc | 全部閉じる | 全部閉じる | 既存メニューの動作 |
