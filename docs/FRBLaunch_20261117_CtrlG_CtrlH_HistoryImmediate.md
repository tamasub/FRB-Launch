# FRB Launch — Ctrl+G／Ctrl+H 履歴を直接表示（2026-11-17）

## 対象・変更方針

入力元：`launch_app_20261117_115745.zip`。
既存の履歴データ／表示UI／矢印キー操作を変更せず、ショートカットを「ボタンへのフォーカス」から「既存ポップアップの即時表示」へ変更。

| キー | 変更前 | 変更後 | 開いたあとの操作 |
|---|---|---|---|
| Ctrl+G | パンくずの履歴ボタンにフォーカスし、↓で表示 | **パンくずの保存フォルダー（お気に入り）一覧を即表示** | ↑↓で選択、Enterでフォルダーへ移動、Escで閉じる |
| Ctrl+H | Files List のフォルダー検索履歴ボタンにフォーカスし、↓で表示 | **Files List のローカル検索履歴を即表示** | ↑↓で保存キーワードを選択、Enterで検索欄へ反映、Escで閉じる |

- Ctrl+G と Ctrl+H の履歴は別データ。Ctrl+G は登録フォルダー、Ctrl+H はFiles List で利用した **検索キーワード履歴**。メイン検索（Ctrl+F）の履歴も別。
- 履歴を開いた状態で同じショートカットをもう一度押しても、ポップアップを閉じない・選択状態を初期化しない。
- Ctrl+G から Ctrl+H（逆も同様）へ切り替える場合は、元のポップアップを閉じてから新しい方を開く。
- Tab の6地点フォーカス巡回は変更なし。Tab でパンくず・検索欄へ移動した場合の既存「↓で履歴を開く」動作も保持。
- フォルダーの保存登録が0件のとき、Ctrl+G は従来どおりポップアップを開かない。
- `config/`、`defaults/`、個人データ、履歴JSONは一切変更しない。

## 差分ファイル

- `src/app.py`：ショートカット呼び出しを直接表示へ変更。
- `src/expanded_view.py`：既存ポップアップの再利用、フォーカス・矢印キー対応、連打時の維持。
- `tests/test_ctrl_gh_history_open_immediately_20261117.py`：新仕様の非GUIテスト。
- `tests/test_launch_20261116_ctrl_h_and_chevron.py`、`tests/test_launch_20261116_five_keyboard_changes.py`：旧「フォーカスのみ」前提の検査を新仕様へ更新。

## テストとWindowsでの確認

Python構文検査と関連テスト（Qt非依存）を実施。PySide6/Windows実画面のための実機テストはこの環境では実施できない。

1. Files画面でCtrl+Gを押し、即座にパンくず保存フォルダー一覧が開くこと。↓/↑/Enter/Escが動くこと。
2. Files画面でCtrl+Hを押し、即座にFiles Listローカル検索履歴が開くこと。↓/↑/Enter/Escが動くこと。
3. 履歴表示中に再度同じキーを押しても閉じず、選択行が保持されること。
4. Ctrl+G→Ctrl+H→Ctrl+Gで表示が切り替わること。Tabフォーカス巡回、Ctrl+F、通常のマウスクリックはそのまま動くこと。
5. 旧版にも存在する一部の陳腐化したテストは今回の変更対象外（オリジナルZIPでも同一失敗を確認）。
