# FRB Launch 2026-11-16 追加修正（差分ZIP）

対象：`launch_app_20261116_204140.zip` を基準とする差分。**フルパッケージではありません。**

## 修正した点

### ① Launch Menu の ▶ サイズ統一

- `Launch Menu` を、既存の `Filesリスト` / `新規作成` と同じ `RemoteFolderActionsMenu._paint_action_chevrons()` に接続。
- Windows/Qt ネイティブの大きな三角を背景で隠して、既存の **4 × 8 px** の三角を重ねる。
- サブメニューの構造やマウスホバーは変更しない。

### ② Ctrl+H：Files List 内の検索履歴

- **Ctrl+F**：メイン検索に移動（既存）
- **Ctrl+G**：パンくずの保存フォルダー一覧に移動（既存）
- **Ctrl+H**：Files List のローカル検索履歴ボタンに移動（追加）
- **↓（1回目）**：従来の検索履歴メニューを開く。
- **↓ / ↑（以降）**：登録済み検索キーワードを選択。端で折り返す。
- **Enter**：選択したキーワードをFiles Listの検索ボックスへ反映。
- **Esc**：閉じて履歴ボタンへ戻る。

※メイン検索/パンくず/Files List検索のデータ保存先とメニューUIはそれぞれ現状のまま。**操作だけを統一**。既存のファイル（`files_list_search_history.json`）はそのまま利用。

※登録/削除などのメニューコマンドは従来のマウスUIを保持。今回の上下カーソルは「登録済みキーワード」のみを巡回する。

## 手元での確認ポイント（Windows実機）

1. Files Exp の登録済みルートを右クリックし、`Launch Menu` の矢印が `Filesリスト` や `新規作成` の矢印と同じ大きさであること。
2. Files 画面を表示し、Ctrl+Hで Files List 見出し左側の履歴アイコンへキーボードフォーカスが移ること。
3. ↓で履歴が開き、再度↓で履歴項目にフォーカスが移ること。さらに↓↑で選択が巡回すること。
4. EnterでFiles Listの検索文字が選択履歴に切り替わること。Escで閉じられること。
5. 履歴メニュー表示中もぐりぐりボタンのクリック/ホイールが利用できること。
6. Ctrl+F、Ctrl+Gの動作がこれまでどおりであること。
