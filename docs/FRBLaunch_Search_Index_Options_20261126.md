# 2026-11-26 メイン検索・ファイル索引設定

## 適用方法
Launch を完全終了し、差分 ZIP を Launch リポジトリのルートに上書き展開。EXE 利用時は `_build_windows.bat` で再ビルド。設定を保存した場合も完全終了・再起動して反映する。

## 変更仕様
1. メイン検索欄をクリックしても履歴を自動表示しない。List からメイン検索へ戻っても検索文字列を維持する。▼、ホイール、履歴ショートカットは維持。
2. ファイル検索の ViewDef に最大探索階層、除外ファイル名、除外フォルダー名、除外フォルダーパターン、走査エラー時動作、自動更新の待機秒数・間隔・並列数を追加。`index_target` は非公開。`max_depth` は従来の null と編集用 -1 の両方を無制限として扱う。既存の System/User/EffectiveOptions 合成方式を維持する。
3. 起動後待機の標準は 300 秒。定期更新間隔は標準 30 分を維持し、0 を許容する。auto + 0 は常駐プロセス起動後の一度だけ（画面再表示では走査しない）。手動更新可能。0 では rename/delete 後の追加自動走査も抑止するため、更新するまで検索結果が古い場合がある。正の間隔では起動待機終了後に定期タイマーを開始する。
4. `view_def` はデフォルト除外しない。フル・増分走査の強制除外を撤廃し、設定の `exclude_name_contains` に一本化する。既存 User の明示値は変更しない。
5. SQLite はファイル行のみ保持。フォルダー結果は対象ファイルの直上ディレクトリから検索時に生成・重複排除。フォルダー名・パス検索と Exp 連携を維持する。空フォルダーや対象拡張子のファイルがないフォルダーは結果に出さない。旧 index_target 値は読み込み時に files に正規化する。旧 DB は検索時にフォルダー行を無視し、次回正常走査で移行する。オフラインルートの既存キャッシュは従来の保護方針に従う。SQLite の物理サイズはページ再利用のため直ちに縮まるとは限らない。
