# Exp Keyboard Ex — 枠線描画の修正（2026-11-20）

## 症状
- `Exp Keyboard Ex` の角丸メニューで、右辺・下辺の輪郭が見えない。
- 前回の枠線調整を適用しても改善しない。

## 原因
- `SlashExpMenu` クラスに **同名の `paintEvent` が2つ**存在していた。
- Pythonでは後に定義された `paintEvent` が有効になるため、前のハンドラに追加した枠線描画は実行されなかった。
- `NoDropShadowWindowHint` の影無効化はすでに設定されていたが、枠線の代わりにはならなかった。

## 修正
- `paintEvent` を1本に整理。
- 通常時とスクロール時のどちらも、処理の最後に独立した角丸の輪郭を描画。
- 右辺・下辺がQRegionの角丸マスクに切られないよう、輪郭線を2.5px内側へ配置。
- `NoDropShadowWindowHint` を維持。ネイティブ影に依存しない描画方式。
- **今回の差分では配色・表示位置・探索ルール・メニュー高さは変更していない。**
