# FRB Launch — Obsidian本体ウィンドウの保管庫切り替え（2026-11-18）

## 適用元

`launch_app_20261118_214357.zip`（ユーザー提供の最新フルソース）

## 目的

Files Listで別保管庫のMarkdownをダブルクリックした場合に、現在のObsidian本体ウィンドウを第3列に閉じ込めたまま「切替不可」となる状態を解消する。

## 変更した責務

- `src/studio_preview_panel.py`
  - **同じ保管庫**：既存の検証済みObsidian本体ウィンドウを使用し、既存Markdown leafでノートを切り替える（従来機能を維持）。
  - **別保管庫**：CLI/対象保管庫の登録状況を先に確認 → 現在の本体HWNDを元の親・ウィンドウ枠へ戻し、デスクトップに表示（**Obsidianプロセスは終了しない**） → 新しい保管庫のURIを1回要求 → Obsidian CLIでノートと本体タイトルを検証 → 一意に一致したHWNDのみ第3列へ収容する。
  - Win32で親の解除を確認できない場合は、旧ウィンドウを保持して切り替えを中止する。
  - **Studio表示後のObsidian再選択**：退避済みObsidian HWNDを、退避時に記録した**保管庫IDが一致した場合のみ**再利用する。他の保管庫の退避ウィンドウは触らず、対象保管庫の通常の検証処理へ進む。
  - CLI処理中の連続ダブルクリックは最新版の対象を待ち行列に保持し、切替実行中のウィンドウを強引に奪わない。
  - 診断ログへ `VAULT_CHANGE_REQUEST` / `VAULT_CHANGE_RELEASE` を追加（保管庫IDはハッシュのみ。ノート本文やパスは記録しない）。
- `tests/test_obsidian_vault_switch_20261118.py`（新規）：異保管庫、同保管庫、CLI処理中、未登録、復元失敗、Studioからの復帰、退避ウィンドウの厳密再利用を検証。
- `tests/test_obsidian_one_popup_invariant_20261118.py`：古いモックを「同一保管庫」「CLI有効」の前提に合わせ、既存の1ウィンドウ動作を回帰検証。

## 実機テスト手順

1. 編集内容を保存するか、Obsidian内に未保存編集が残ることを意識した上でLaunchを再起動する（Obsidian自体は終了させない）。
2. 保管庫Aの `A1.md` をダブルクリック → 第3列へ本体収容。
3. Aの `A2.md` をダブルクリック → **同じ第3列**でノート内容だけ切り替わる。
4. 保管庫Bの `B1.md` をダブルクリック → Aのウィンドウを**デスクトップへ復元** → Bの本体をCLIで検証して第3列へ収容。Bの既存ウィンドウがあればそれを使い、新規ポップアウトは作らない。
5. StudioのJSONをダブルクリック → Studioへ切り替え → Bの `B2.md` をダブルクリック → **Bの退避ウィンドウだけ**を再利用する。
6. Aの `A1.md` に戻る → Bをデスクトップへ復元 → Aの本体を改めて確認して収容する。
7. 第3列の× → Obsidianがデスクトップへ戻り、ノートの編集状態が保持されるか確認する。
8. 万一切り替えに失敗したら、`%LOCALAPPDATA%\FRBLaunch\obsidian_dock_trace.jsonl` を個人情報を確認の上共有する。失敗段階を `VAULT_CHANGE_REQUEST`、`VAULT_CHANGE_RELEASE`、`DOCK_REQUEST`、`CLI_RESULT`、`HWND_SELECTION`、`MAIN_ATTACHED` で切り分ける。

## 安全性・制限

- 別保管庫を同一Obsidianウィンドウの中で直接「中身だけ入替」するわけではない。**保管庫ごとに異なる本体ウィンドウ**を切り替える。
- 旧保管庫の本体ウィンドウは**閉じずにデスクトップへ返す**。明示的なWindow CloseやProcess Killは送らない。
- Obsidianの第3列内でのネイティブ最大化・黒枠・Electron描画問題は**別の課題**。今回の差分では改変しない。
- Windows11・PySide6・Obsidian実機での再収容動作は**未検証**。Linux上ではASTモック／既存テストによる確認のみ。
- CLIが有効でない、未登録保管庫、複数の候補HWND、別Vaultの同名タイトル等で本体を一意に決定できない場合は収容を中断する（適当な窓を借りない）。
