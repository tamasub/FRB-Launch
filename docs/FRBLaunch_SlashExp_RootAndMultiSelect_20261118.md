# FRB Launch `/` UI — Exp枠内配置・カレントフォルダー階層・複数選択ガード

基準：`launch_app_20261118_161953.zip`（2026-11-18）。差分のみ。

## 修正

- `/` 起動直後の第1列は **Files Expのツリー枠内側**（左端+5px、上端+2px）へ。ルートメニューの幅はExpツリーの内部幅に制限。長い一覧の内部スクロール用ウィジェットも、**表示前**に同じ制限幅で生成する。2列目以降は従来の標準幅・長い名前用幅を維持。
- Expのルートには **「（カレントフォルダー）」を出さない**。ルートは実在するExpの登録根のみを示し、架空のルートに対するフォルダー新規作成を誘導しない。
- 階層を開いた後は、その列の実フォルダー／登録済み仮想フォルダーの先頭に「（カレントフォルダー）」を表示。`→` は**その列のフォルダー自身**の既存コンテキストメニューを開く。別のListの選択場所を流用しない。`Enter`はフォルダー自身の行では不実行。`↑↓`、`←→`、末端Enterの既存仕様を維持。
- Launch JSONの複数行選択に対して、単一アイテム専用の `簡易編集...` / `詳細編集...` / `JSON参照IDをコピー` を表示したまま**無効化**。一括登録解除は従来どおり使用可能。単一選択なら従来どおり有効。
- Studio第3列の外出しボタンはStudioの起動後は常に表示。収容完了前のみ無効化。既存の私有パイプ承認・detach手順は維持。

## 今回スコープ外

- Obsidianの収容・前面表示・色・他のMarkdownタブへの切替・消失検知は**一切変更しない**。
- ぐりぐり位置・Shift選択機能は前版維持。
