# FRB Launch ぐりぐりレール（丸ボタン）左右2領域・長押し無効・外枠描画改善

- 対象: `launch_app_20261115_212553.zip`（ユーザー添付21:25版）
- 返却: **差分ZIP**。含まれる `src/` と `tests/` をソースフォルダーへ上書き展開してください。
- 設定は既存の「リモコン表示 → ぐりぐりボタンのみ」のまま。初期値 OFF などの4択設定は変更しません。

## 動作仕様

1. 丸ボタンをCSSの `border-radius` 表示から、アンチエイリアス付きの `QPainter` 円描画へ変更。輪郭は52px領域の端から約2px内側へ描いて、楕円マスクで途切れないようにしました。
2. 丸ボタンの中央に薄い**縦点線**を描きます。上に「ぐりぐり」、左右に小さく `Exp` / `List` を表示します。ポインターがある側に小さな点を表示します。
3. ボタン内部の**左半分**にポインターがあればFiles Exp、**右半分**ならFiles Listが操作対象です。中心線は右側扱いです。
4. 上下ホイール、左シングルクリック・ダブルクリック・右クリックは、元の `WheelPad` と共通の意味コマンドを発行します。操作対象の変更はボタン内部のマウス移動・ホイール・クリックイベントにより行われます。別ボタンや長押しは不要です。
5. 丸ボタンだけ**長押しのExp/List選択メニューを無効化**。450ms以上押して放してもクリックと判定しません。既存の独立Remoteの長押し挙動は一切変更しません。
6. 独立Remoteが非表示の「ぐりぐりボタンのみ」でも、左側操作はLaunch内の既存Files Expツリーを対象にします。フォルダーやListのデータを作り直しません。
7. 丸ボタンは引き続きLaunch内の子Widgetです。Launch移動・リサイズ・Exp列幅変更に追従。通常のとんとんレール、4択設定、独立Remoteは既存のままです。

## 実機確認（Windows）

1. 「リモコン表示 → ぐりぐりボタンのみ」で52pxの円と、欠けない外枠・中央点線・左右 `Exp/List` を確認する。
2. ボタンの**左半分に置いて上下ぐりぐり**→ Files Expのカレントが動き、右半分ではFiles Listが動くこと。
3. ボタン内で**左右へ数px移動**するだけで操作対象が変わり、ウィンドウ外へポインターを移す必要がないこと。
4. それぞれの半分でクリック・ダブルクリックを試し、既存Remoteの対象別操作と一致すること。
5. 450ms以上の長押しで、対象選択のメニューもクリック確定も発生しないこと。
6. Expの分割線をドラッグ、Launchの移動・リサイズ、OFF/ON切替、別Windowモードでも既存動作を維持すること。
