# FRB Launch — `/` で開くExp矢印ナビ（試作）

2026-11-18 / 差分ZIP（既存のExp・List動作を変更しない追加モード）

## 目的

Exp／Files Listのいずれかにキーボードのカレントがあるとき、`/` でExp第1階層を「コンテキストメニュー形式」の専用ポップアップとして表示する。ぐりぐりボタンが表示されていれば、その右側に出す。表示されていない場合はFiles List側にフォールバックする。

## キー契約

| 操作 | 意味 |
|---|---|
| `/` | Exp第1階層の専用メニューを表示（Exp / List / 操作対象がExpかListのぐりぐりボタン） |
| `↑` `↓` | 現在のポップアップ列で項目を選択（折り返しあり） |
| `→` | 下位階層があるとき、右に子メニューを表示。**末端では既存のコンテキストメニューを表示** |
| `←` | 親メニューへ一階層戻る。第1階層では閉じる |
| `Enter` | **途中階層では何もしない**。末端でのみ選択フォルダー／仮想カテゴリをFiles Listへ確定表示 |
| `Esc` | 専用メニュー全体を閉じる（実行しない） |

- **`→` でフォルダーを開く・Files Listを切り替える副作用なし。** 末端の右矢印でも、既存コンテキストを出すだけでディレクトリを勝手に移動しない。
- 既存の右クリック、ぐりぐりRunner、ExpのEnter・→、Listのショートカットは今回変更しない。これまで報告された既存コンテキスト内の「Filesリスト」と「新規作成」のキー競合は別件として保留。
- Expが持っている実際のモデルを使用。仮想Page・カテゴリー／登録実フォルダー／PCを含み、空白の装飾区切りを除外。子要素は押した階層だけ遅延読み込み。別の設定JSON・ショートカット登録は作らない。
- 末端の「実行」は現時点では**対象フォルダーをFiles Listに表示する操作**（OS上のExplorer新規起動ではない）。
- 既存コンテキストメニューのアイテムは既存の実装へ委譲し、登録済みのルートはStudio識別子を検証したうえで詳細編集メニューを保持。
