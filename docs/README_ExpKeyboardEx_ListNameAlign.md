# FRB Launch / Exp Keyboard Ex — Files List「名前」列へ初期メニュー位置・幅を同期

適用元: `launch_app_20261120_095101.zip`（ユーザー添付の最新フルZIP）
形式: **差分ZIP**。同名パスを上書きしてください。

## 今回の変更

- `/` で開く**第1階層**のポップアップ左上を、Files Listの「名前」列（列ID=0）のヘッダー左上へ配置。
- 位置は QHeaderView の `sectionViewportPosition(0)` + `mapToGlobal()` から実際の表示座標を取得。
  列のドラッグ並び替え・横スクロールにより「名前」列が移動しても追従する。
- 第1階層メニューの幅を、表示時点の `sectionSize(0)` に**厳密に一致**させる。
  名前列の幅を変更してから `/` を開き直せば変更後の幅を使用する。
- 検索行や長い一覧用のスクロールウィジェットも、最初の幅決定のあとに生成する。
- **第2階層以降のカスケード幅は従来どおり自動判定。**
- パンくず論理パス（唯一の探索起点）、`/` 再押下で閉じる操作、Right/Enter、Exp登録ルートは変更しない。

## 変更ファイル

- `src/app.py` — 名前列の実際の画面座標・幅を起点として利用
- `src/slash_exp_navigation.py` — 第1階層だけ実幅を指定できるよう調整
- `tests/test_slash_exp_navigation_20261118.py` — 起点・幅・長い一覧・子階層のテスト更新

## Windowsでの実機確認

1. Files Listの名前列の幅をドラッグで変更 → `/` で第1階層の左端・幅が一致するか確認。
2. 名前列の幅を変更し、メニューを閉じて再び `/` → 幅が追随するか確認。
3. `/` → Rightで第2階層を展開 → 第2階層は自動幅のままか確認。
4. 行数が多いフォルダーで `/` → 上下移動・検索時にメニュー枠がずれないか確認。
5. `/` 再押下でメニューを閉じられるか、Enter着地後のパンくずが従来どおりか確認。

※メニューが画面右端からはみ出す場合、Qt/アプリ既存の画面端補正が表示位置を調整する可能性があります。
