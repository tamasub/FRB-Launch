# FRB Launch `/` 矢印ナビ — 列幅／Expオーバーレイ改修（2026-11-18）

基準：`launch_app_20261118_150002(1).zip`。変更対象は `/` 操作の見た目と初期位置のみ。既存のFiles Exp／Listのコマンド動作、Enter／矢印キー操作、検索、全件リスト／固定枠スクロールは維持する。

## 変更

1. `/` の初期メニューは、ぐりぐりボタンやFiles Listを基準にせず、**現在表示中のFiles Expツリー先頭**（viewport左上+6px）に重ねて出す。起点を子列4つ分だけ左へずらす旧予約ロジックは削除。個別の子列は既存の選択行基準で配置し、画面端では従来どおり位置補正する。
2. メニュー幅を、列内にある**元の文字列の実測幅**から、通常270px／長名380pxの2段階で決める。閾値212px。列を表示する前に決定し、スクロール中は変更しない。メニュー件数やスクロールバーの有無で標準幅が変わることはない。
3. 長いメニューの`QTreeWidget`も列幅に追随（メニュー幅−18px）。検索欄は既存のレイアウトを利用。文字は表示用のみ末尾`…`で省略し、検索・ツールチップの全文は変えない。
4. スクロール用リストに独立22pxの固定幅矢印列を設け、矢印を右揃え。アイコンサイズ18pxで統一。通常QMenu行も従来の右端小矢印を維持。
