# FRB Launch Gitコミット画面・クリック操作修正（2026-11-16）

## 適用対象
`launch_app_20261116_225043.zip` を基準にした差分です。
FRB Launch のプロジェクトルートに、`src/` / `tests/` をフォルダー構造ごと上書きしてください。
設定JSON・リポジトリ情報・Git履歴には触れません。

## 修正原因
旧コードの `RemoteTextDialog.background_click()` が、ボタン選択モードに移った後も
常に `True`（クリックを消費する）を返していたため、ぐりぐりでOKを選択した後の
余白クリックがボタンの実行に届いていませんでした。
また `focus_buttons()` は初期Cancelの表示を明示選択扱いにしていました。

## 新しい操作
1. Gitコミット画面が開いたら、どこからぐりぐりしても「コミット先」を選べる。
2. 余白を一度クリック → OK/Cancel選択モードへ移行（Cancelが安全な初期選択）。
3. ぐりぐりまたは左右キーでOK/Cancelを**明示選択**。
4. 余白クリック／ぐりぐりボタンクリック → 明示選択したボタンを実行。
5. ダイアログ内の実際のOK/Cancelボタンは、そのボタンを通常クリックして直接実行可能。
6. リポジトリ選択欄をクリックすれば、リポジトリ選択モードへ戻れる。

## 安全対策
- 1回目の余白クリックでOK/Cancelが押されることはありません。
- ボタン選択モードへ移った直後のCancel表示は「明示選択」として扱いません。
- その後ぐりぐり等で選び直す前の余白クリックでは、OKもCancelも実行しません。
- ボタンを選択しても、既存の「Gitコミットの確認」画面は引き続き表示されます。
- ダイアログ外の別アプリのクリックは確認として受け付けません。
