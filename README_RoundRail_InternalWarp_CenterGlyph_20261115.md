# FRB Launch — ぐりぐりレール／丸ボタン内ワープ＋中央絵文字

起点：`launch_app_20261115_230909.zip`（2026-11-15 23:09版）

## 今回の変更

1. **リモコン表示＝「ぐりぐりボタンのみ」、マウス自動移動＝ON**
   - コンテキストメニュー「Exp列へ戻る」：丸ボタン左半分（幅の1/4・高さの1/2）へカーソルを移す。
   - コンテキストメニュー「List列へ進む」：丸ボタン右半分（幅の3/4・高さの1/2）へカーソルを移す。
   - 行の上へ飛ぶ既存の処理は、このモードでは使わない。
   - メニュー操作後、カーソルが人間の操作で移動していた場合は後追いしない。
   - ボタンが表示されていない場合は、別の位置への代替ワープはしない。
2. **上記以外のモード**
   - 使用しない・リモコンウィンドウ（1.5列／別Window）：従来どおり移動先のカレント行へカーソルを移す。
   - マウス自動移動＝OFF：従来どおりマウスは移動しない。
3. **丸ボタンの中央絵文字**
   - 既存リモコンのぐりぐりボタンと同じ「🔘」を円の中央に表示。
   - 「ぐりぐり」は上、「Exp」「List」は下へ配置。
   - 縦点線は絵文字の下で区切り、左右の操作境界（ボタン幅の半分）は変更しない。
   - 絵文字はマウスイベント透過。ホイール・クリック・ダブルクリックは引き続き丸ボタン本体が受け取る。

## 差分ファイル

- `src/app.py`：コンテキストメニューからの列切替時の、丸ボタン内ワープを追加。
- `src/launch_remote.py`：中央絵文字と文字／点線の表示位置を調整。
- `tests/test_round_rail_internal_warp_emoji_20261115.py`：追加テスト。

## 適用

ZIPを23:09版の**ソースフォルダー直下**へ上書き展開して、`_run_windows.bat` から起動。

## 確認手順

1. 設定「マウス自動移動＝ON」「リモコン表示＝ぐりぐりボタンのみ」。
2. 丸ボタンの右半分から右クリック→「Exp列へ戻る」：カーソルが丸の**左半分**に戻ること。
3. 丸ボタンの左半分から右クリック→「List列へ進む」：カーソルが丸の**右半分**に移ること。
4. 丸の真ん中に「🔘」が表示され、ホイールとクリックに影響しないこと。
5. 「リモコン表示＝使用しない」へ戻すと、メニュー操作後は従来のカレント行へのワープになること。
6. マウス自動移動＝OFFではカーソルが動かないこと。
