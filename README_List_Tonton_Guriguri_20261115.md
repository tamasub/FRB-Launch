# FRB Launch：Files List とんとんレーン「ぐりぐり」対応

## ベース

- `launch_app_20261115_200629(1).zip`（ユーザー指定のひとつ前の資材）
- 前回試作の「左長押し＋上ぐりぐり3ノッチでFiles Expへ移動」は **引き継がない**
- 本差分は `src/expanded_view.py` のみ変更。`tests/test_tonton_lane_wheel_hybrid_20261115.py` を追加。

## 実装範囲

**Files List 左端の24pxのとんとん親帰りレーンだけ**を対象とする。

| ポインター位置 | ホイール操作 |
| --- | --- |
| Files Listの行 | 従来の高速ハイブリッドぐりぐり（変更なし） |
| Files Listの左端とんとんレーン | 上記と同じListのWheel処理へ転送（今回追加） |
| Files Exp | 変更なし |
| その他 | 変更なし |

- 左ボタンを押さず、通常のホイールだけで操作する。
- スクロール可能な場合は、従来同様にListの縦スクロールを優先する。
- スクロール端や全行表示の場合はListのカレント行を上下移動する。
- とんとんレーン上からの端でのカレント移動は、カーソルをレーン上に残す（List行へ勝手にワープさせない）。
- 左クリック＝選択解除、ダブルクリック＝親帰り、右クリック＝フォルダー操作を維持。
- シュリケン／Remote／Exp／ボタン操作の処理は変更しない。
- 修飾キー押下中やマウスボタン押下中は、レーン専用Wheel転送を行わない。

## 実機確認（Windows）

1. `_run_windows.bat` で起動、Filesタブを開く。
2. Files Listに複数行があるフォルダーを選び、左端の**幅24px**のとんとんレーンにカーソルを置く。
3. ボタンを押さず上・下にホイール：Listの行上でぐりぐりした場合と同じスクロールができること。
4. 行数が少なく全表示されるフォルダーでも上下にホイール：Listのカレントが移動し、カーソルは24pxレーン上に残ること。
5. シングルクリックで行選択解除／ダブルクリックで親フォルダーへ／右クリックで既存メニューが出ること。
6. Exp側、Listの通常の行上、検索欄のホイール動作に変更がないこと。
7. Listに行が0件／長い行リスト／マウス自動移動ON・OFFを確認する。
