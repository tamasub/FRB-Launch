## FRB Launchでできること

FRB Launchは、**Windows 11向けの無料ランチャー**です。毎日使うアプリ、フォルダー、ファイル、Webのブックマーク、バッチファイルなどを、ひとつの入口から探して実行できます。

初めての方には、まず**普通に便利なランチャー**として使ってほしい。独自のマウス操作やAIとの連携は、必要になったときに試せる追加の楽しみです。

| できること                     | 使う人にとってのメリット                                                      |
| :------------------------ | :---------------------------------------------------------------- |
| 📁 **保存場所と「使うための整理」を分ける** | 元のファイルを移動せず、仕事別・目的別のメニュー階層や並び順を自由に組み立てられる                         |
| 🚀 **よく使うものを一か所に集める**     | アプリ・ファイル・フォルダー・URL・バッチ／スクリプトをまとめて呼び出せる                            |
| 🖱️ **ドラッグ＆ドロップでかんたん登録**  | エクスプローラーのファイル・フォルダーも、Chrome／EdgeのURLも、ドラッグしてLaunchのメニューアイテムに追加できる |
| 🔎 **ごちゃまぜサーチ**           | 登録したものを種類の違いを気にせず、ひとつの検索窓から探せる                                    |
| 🧠 **わがままサーチ**            | AND・OR・括弧を組み合わせ、探し方を自分で指定できる                                      |
| ⌨️ **キーボードでもマウスでも操作**     | 矢印キー・Enter、マウスホイール、クリックなど、好きな方法を選べる                               |
| 📅 **定型入力・便利なアクション**      | 日付やよく使う文章の入力、登録したコマンドの起動など、繰り返し作業を減らせる                            |
| ⌨️ **Keyboarder Ex**      | 現在のフォルダーから、矢印キーと文字入力で階層をたどり、開く・選ぶ・操作する                            |
| 🤝 **第3列へのゲスト招待**         | サクラエディタ・Obsidian・Visual Studio Codeと連携し、ファイル探索と編集をつなぐ             |
| 🛠️ **FRB Commander**     | ViewDefを用意したPowerShellスクリプトを、候補やファイル・フォルダーを選びながら実行する              |
| 🧩 **JSONでメニューを管理**       | 設定をデータとして扱え、AIにメニューの整理を相談したり、AIが作った小さなツールを登録したりできる                |

> **探す対象はごちゃまぜ。探し方はわがまま。**  
> ごちゃまぜサーチは「何を探すか」、わがままサーチは「どう探すか」を担当します。

※検索の対象や範囲は機能・画面によって異なります。「登録したものを探す機能」が、PC内の全ファイルを無条件に検索するという意味ではありません。

## まずはこんな使い方から

**メニューへの登録は、ドラッグ＆ドロップでもかんたん！**

- **エクスプローラーから**フォルダーやファイルをFRB Launchのメニューへドロップすると、メニューアイテムとして追加できます。

  <img width="300" height="200" alt="image" src="https://github.com/user-attachments/assets/d43eaeab-bb9b-4b09-8ff5-965a96350799" />

- **Chrome／Edgeから**WebページのURLをドラッグしてFRB Launchのメニューへドロップすると、URLのメニューアイテムとして追加できます。

  <img width="300" height="200" alt="image" src="https://github.com/user-attachments/assets/56baae66-ed22-46b2-a898-61141e7386ee" />

ファイルの保存場所やURLそのものを移動する必要はありません。よく使うものへの入口を、Launch側に作れます。

1. 毎日使うアプリ、ファイル、フォルダー、ブックマークを登録する。
2. 保存場所は変えずに、**仕事別・目的別のメニュー**を作る。
3. 検索して選び、Enterやクリックで実行する。
4. もっと楽にしたくなったら、ぐりぐり操作やAIを使ったメニュー整理を試す。

たとえば、AIに作ってもらった日付入力用の小さなスクリプトを登録すれば、日常の操作からすぐに呼び出せます。**AIが作ったものを、毎日の仕事で使う場所までつなぐ**。それが「AI協働を身近にする」の意味です。

## はじめ方

### 動作環境・配布状況

- **Windows 11（64-bit / x64）** を対象に公開しています。
- 利用料金は**無料**です。
- 一般環境での動作や品質が十分に検証済みという意味ではありません。
- ポータブル配布版には実行に必要な環境が含まれ、通常利用でPythonやNode.jsの個別インストールは不要です。
- Windows 10以前やWindows on ARMは動作保証対象外です。

### ダウンロードして起動する

**[FRB Launch — GitHub Releases](https://github.com/tamasub/FRB-Launch/releases/)**

1. `FRBLaunch_X.X.XX_portable.zip` をダウンロードします。
2. ZIPを任意のフォルダーへ**すべて展開**します。ZIP内から直接EXEを起動しないでください。
3. 展開先にある `FRBLaunch.exe` を起動します。
4. **デスクトップの空き領域をダブルクリック**するとLaunchを呼び出せます。`Ctrl + Shift + ;` でも呼び出せます。
5. 画面右上の**歯車アイコン**から、お好みの表示・操作方法を設定してください。

初回はWindowsのセキュリティ確認画面が表示される場合があります。配布元とファイルを確認してから実行し、セキュリティ機能を無効化しないでください。

### 基本操作

| 操作 | 内容 |
| :-- | :-- |
| デスクトップの空き領域をダブルクリック | Launch画面を呼び出す |
| `Ctrl + Shift + ;` | Launchを呼び出す（設定・キーボード環境によって調整可能） |
| 矢印キー | メニューや階層を移動 |
| `Enter` | 選択項目を実行 |
| `Ctrl + F` | 検索へ移動 |
| マウスホイール | 対応画面でスクロール・選択 |
| Files Listの対応する余白をダブルクリック | 「とんとん親帰り」で親フォルダーへ |

画面や設定によって使える操作は異なります。通常のマウス・キーボード操作を基本とし、独自操作は必要に応じて使えます。

## キーボード操作ガイド

**右手だけでも、探す → 選ぶ → 開く。** 通常のキーボード操作に加え、矢印キー周辺とテンキーを活用した操作（小指Zero）を用意しています。

以下は2026年11月27日のソース（Launch本体 v0.9.14）を基準にした一覧です。Launch内の対応画面で有効です。ゲストアプリや外部アプリ、文字入力・名前編集中などでは、その画面の操作が優先される場合があります。

### まず覚えたいキー

| キー | 動作                           |
| :------------------------- | :--------------------------- |
| `Ctrl + Shift + ;` | Launchを呼び出す（初期設定。変更可能）       |
| `Home` | Files画面のHOMEボタンと同じ処理         |
| `F3` / `Ctrl + F` | メイン検索へフォーカス                  |
| `Ctrl + G` | パンくずの保存フォルダー履歴を直接表示          |
| `Ctrl + H` | Files Listのフォルダー検索履歴を直接表示    |
| `Ctrl + I` | 歯車の設定メニューを表示                 |
| `/` / Windowsメニューキー | Files画面でKeyboarder Exを開く・閉じる |
| `Ctrl + Windowsメニューキー` | Launchのアクションメニューを表示          |
| `Tab` / `Ctrl + →` | 次の操作エリア・入力項目へ移動              |
| `Shift + Tab` / `Ctrl + ←` | 前の操作エリア・入力項目へ移動              |
| `Enter` / テンキー `0` | 選択項目を開く・実行・確定する              |
| `Esc` | メニューを閉じる、選択を取り消すなど（画面による）    |

Windowsメニューキーとは、キーボードのアプリケーションキー（メニューの絵が付いたキー）のことです。Windowsロゴキーとは異なります。

### 小指Zeroと右手操作

- テンキー `0` は非入力状態で `Enter` 相当。検索欄・数値入力欄・名前編集中は数字の入力を優先します。NumLock OFFでも、テンキー由来と識別できる場合はEnterとして扱います。
- `Ctrl + →` / `Ctrl + ←` は、対応画面でTab / Shift+Tab相当のフォーカス移動をします。Launch内の入力欄では通常の単語単位カーソル移動より、この割当が優先されます。
- **テンキー `1` は通常の数字入力に戻りました。Tabの代用ではありません。** メイン数字段の `0` / `1` や独立したInsertキーはテンキーの代用キーではありません。
- WindowsメニューキーでKeyboarder Ex、`Ctrl + Windowsメニューキー` でLaunchのアクションメニューを呼び出せます。後者ではLaunch検索履歴・パンくず履歴・フォルダー検索履歴・設定を選べます（Files専用項目はFiles画面で利用）。

### Files画面：フォーカスの移動

`Tab` または `Ctrl + →` で、次の順に時計回りに移動します。

```text
メイン検索 → パンくず履歴 → フォルダー検索 → Files List → Files Exp
     ↑                                                    │
     └────────────── Browser（利用可能な場合） ←──────────┘
```

`Shift + Tab` または `Ctrl + ←` は逆方向です。Browserを利用できない場合はFiles Expからメイン検索へ戻ります。Filesタブ自体は巡回に含めません。

検索・パンくず履歴にフォーカスした状態では `↓` で履歴を開き、`↑` / `↓` で選択、`Enter` で適用します。`Ctrl + G` / `Ctrl + H` はフォーカス移動だけではなく、履歴を直接開きます。

### Files Exp・Files List

| キー | 対象 | 動作 |
| :-- | :-- | :-- |
| `↑` / `↓` | Exp / List | 行を移動・選択 |
| `Enter` | Exp | フォルダーを展開・表示（Expで探索を継続） |
| `→` | Exp（固定2列構成） | 現在のフォルダーを表示し、Listへフォーカスを渡す |
| `←` | Exp | ツリーの折り畳み・親項目への移動など |
| `Enter` | List | フォルダーへ移動、ファイルや登録項目を開く |
| `→` | List | **右クリックと同じコンテキストメニュー**を表示（即実行しない） |
| `←` | List | 先頭行へ移動し、さらに押すとExpへ戻る（固定2列構成） |
| `Insert` | List | 行の選択を解除し、現在のフォルダーを操作対象にする。続けて `→` でフォルダーのメニューを開ける |
| `Shift + ↑` / `Shift + ↓` | List | 連続した行を範囲選択 |
| `Ctrl + C` / `Ctrl + X` | Exp / List | 対応する実ファイル・フォルダーをコピー／切り取り |
| `Ctrl + V` | Exp / List | 対応するフォルダーに貼り付け |
| `Delete` | Exp / List | 削除操作（対象や確認画面に従う） |
| `F2` | Exp / List | 対応するファイル・フォルダーの名前変更 |
| `F5` | Exp / List | フォルダー情報を更新 |
| `PageUp` / `PageDown` | List | ページ単位で移動。先頭行で単独の `PageUp` は親フォルダーへ |
| `Backspace` | メイン検索結果のList | 検索を解除して元のフォルダー表示へ戻る |
| `Esc` | List側フォルダー検索欄 | 検索文字がある場合、文字をクリア（フォーカス維持） |

Expの登録ルートや仮想項目など、物理ファイル操作が許されない対象では実行できない操作があります。Listで現在のフォルダーを操作するときは、`Insert` → `→` が便利です。

### コンテキストメニュー・設定・履歴

| キー | 動作 |
| :-- | :-- |
| `↑` / `↓` | 項目を移動 |
| `→` | 子メニューを開く（階層がある場合） |
| `←` | 親メニューへ戻る／ルートを閉じる |
| `Enter` / テンキー `0` | 選択を確定・実行（子メニューは展開） |
| `Esc` | メニューを閉じる |

操作確定後は不要になったメニューを閉じ、処理内容に応じて砂時計・処理中メッセージ・進捗を表示する構成です。階層をたどっている間はメニューを維持します。

**Gitコミット操作：** コミット先の選択ダイアログでは、ぐりぐりによるリポジトリ選択やOK/Cancelの操作も利用できます。余白クリックだけではコミットされず、実行前には別途確認画面が表示されます。

### キーボード手裏剣スクロール

| キー | 動作（Files List） |
| :-- | :-- |
| `PageDown` または `PageUp` を同方向に4連打 | 慣性滑走を開始 |
| 滑走中に同方向の `↑` / `↓` | 加速（連打も可） |
| 滑走中に逆方向の `↑` / `↓` | 減速 |
| `Space` / `Esc` | 滑走を止めて着地 |

1〜3打目は通常のページ移動、4打目で滑走開始。キーの押しっぱなしによる自動リピートは4連打として扱いません。上端・下端では無理に滑走しません。

### Page・登録メニューのショートカット

| キー                                         | 動作（対応するメニュー表示時）   |
| :----------------------------------------- | :---------------- |
| `Ctrl + F1` ～ `Ctrl + F12`                 | 対応するPageに切り替え     |
| `Ctrl + Shift + F1` ～ `Ctrl + Shift + F12` | 表示中のルート項目を順番に呼び出す |
|                                            |                   |

## Keyboarder-ex

Files画面の現在地（パンくず）を起点に、カスケード形式のメニューでファイル・フォルダーを探索する機能です。`/` またはWindowsメニューキーで呼び出します。検索欄や名前編集中の `/` はKeyboarder Exの起動に使わず、入力欄側の操作を優先します。

| キー                    | 通常のKeyboarder Ex      |
| :-------------------- | :-------------------- |
| `↑` / `↓`             | 現在の列の項目を選択            |
| `PageUp` / `PageDown` | 長い一覧をページ単位で移動         |
| `→`（フォルダー）            | 子階層を開く                |
| `→`（ファイル・終端項目）        | 操作メニューを開く             |
| `Enter`（フォルダー）        | Files Listに移動         |
| `Enter`（ファイル・登録項目）    | 開く・実行する               |
| `Enter`（カレントフォルダー）    | そのフォルダーをFiles Listに表示 |
| `→`（カレントフォルダー）        | そのフォルダーの操作メニューを開く     |
| `←`                   | 一つ前の階層に戻る             |
| 文字入力                  | 現在の列を絞り込む（日本語IME対応）   |
| `Esc` / `/`           | Keyboarder Exを閉じる     |

フォルダーの中身をあらかじめすべて探索せず、必要になった階層を開く方式に改善しています。大量のファイル・ネットワークフォルダーなどでは、読み込みに時間がかかることがあります。

**例：** Filesで `docs` を表示 → `/` → `↓` で項目選択 → `→` で子フォルダーへ → 文字入力で絞り込み → `Enter` で目的のファイルを開く。

Commanderから呼び出した場合は選択専用モードとなり、ファイルやフォルダーを開かずにパスを返します（[FRB Commander](#frb-commander)参照）。

### ぐりぐりボタン・ポインター自動移動は任意

歯車メニューの**「リモコン表示」**は3択です。

| 設定 | 内容 |
| :-- | :-- |
| **使用しない** | **初期値**。標準的な操作で使う |
| リモコンウィンドウ 別Window | 独立ウィンドウとして表示 |
| ぐりぐりボタンのみ | Files Exp / Files Listの境界に丸ボタンを表示 |

**マウスポインター自動移動も初期OFF**です。気に入った方だけONにしてください。自動移動が難しい仮想デスクトップ・リモート環境ではOFFでの使用をおすすめします。

## FRB Launchにゲストを招待しました！

ファイルを探す場所と、ファイルを編集する場所を近づけたい。そんな発想で、Launchの第3列に外部エディターを招待する機能を用意しました。

| ゲスト | 利用イメージ |
| :-- | :-- |
| サクラエディタ | テキスト編集 |
| Obsidian | Markdownの閲覧・編集 |
| Visual Studio Code | ソースコードや各種テキストの編集 |

対応するファイルをFiles Listから開くと、設定・アプリの起動状態に応じて第3列との連携を利用できます。各アプリは別途インストールしてください。すべてのファイル・既存ウィンドウ・環境で同じ動作を保証するものではありません。

歯車 → **オプション設定 → アプリ連携**で、3つのゲストを個別にON/OFFできます。保存後はLaunchを完全終了し、再起動してください。無効にしたアプリは従来の外部起動経路を使用します。既存設定がある場合はその設定が優先されます。

FRB Studioとの連携も従来どおり利用できます。ゲスト連携はPreview機能です。

### Browserも、使う・使わないを選べます

オプション設定 → ブラウザーで内部ブラウザーの利用有無を選べます。保存後の再起動で反映されます。無効時は、明示的なブラウザー指定がないURLをWindowsの既定ブラウザーに渡します。ChromeやEdge、プロファイルを指定した登録項目・取り込んだブックマークの指定先は維持します。

## FRB Commander

AIに作ってもらったPowerShellスクリプトを、毎日の作業で使いやすくするための機能です。

`.ps1` と同じフォルダーに、同じベース名の `.viewdef`（UTF-8のJSON形式）を用意します。Files Listで `.ps1` を選択して右クリック（または `→`）し、**FRB Commanderで実行**を選びます。

ViewDefで入力項目・候補・ファイルやフォルダーの選択方法を定義できます。選択済みの値はパンくずで確認・再編集でき、生成されたコマンドのコピーや実行結果の確認ができます。

| キー | 対象 | 動作 |
| :-- | :-- | :-- |
| `←` / `→` | Commander本体 | 選択項目 → コマンドコピー → 実行へ移動（逆方向も可） |
| `↓` / `/` / `Enter` | 選択項目 | 候補表示・入力開始 |
| `↑` / `↓` | 候補選択 | 候補を移動 |
| `→` / `Enter` | 選択候補 | 候補確定（入力欄はEnter） |
| `←` / `Esc` | 選択候補 | 取消（入力欄はEsc） |
| `Enter` | コピーボタン／実行ボタン | コマンドをコピー／実行確認へ |
| `Ctrl + Enter` | Commander本体 | 実行確認を表示 |

**Keyboarder Exの選択専用モード：** ファイル選択ではフォルダーをたどり、ファイル上の `Enter` / `→` でパスを返します。フォルダー選択ではファイルを表示せず、`→` で下位階層、`Enter` でフォルダー確定。列先頭の「（このフォルダーを選択）」で現在地を選べます。`←` で戻り、`Esc` で取り消します。選択専用モードでは指定された初期ルートより外への移動は未対応です。

スクリプトは明示的な実行確認を経て実行されます。実行後もCommander本体は自動終了しません。閉じるかどうかは利用者が決めます。

現段階はPowerShell（`.ps1`）とCommander用ViewDef v0.1が対象です。元スクリプトに必要な実行環境・依存ファイルは別途用意してください。内容を理解したスクリプトのみ実行してください。

[Commanderのサンプル](examples/commander/README.md) ／ [フォルダー選択の仕様](docs/CHANGE_NOTE_FRB_Commander_FolderPicker_20261127.md)

## 検索とファイル索引

メイン検索と、Files Listのフォルダー検索は別の入口です。

| 検索                 | 内容                                      |
| :----------------- | :-------------------------------------- |
| メイン検索（ごちゃまぜサーチ）    | 登録メニューやアプリ・ブックマーク、設定に従ったファイル索引などを横断して探す |
| Files Listのフォルダー検索 | 表示中の一覧を絞り込む                             |
| Keyboarder Exの検索   | 現在開いているメニュー列の候補を絞り込む                    |

メイン検索は `F3` / `Ctrl + F` で開始し、入力後 `Enter` で検索結果のFiles Listへフォーカスを移します。検索欄に戻っても入力文字を維持します。検索結果のListで `Backspace` を押すと元のフォルダーに戻れます。

わがままサーチの例（対応する検索欄）：`FRB md` は空白区切りのAND、`(FRB or Studio) md` はORのグループとANDの組み合わせです。

### ファイル索引の設定

オプション設定のファイル検索で、対象フォルダーの方式（登録済み／指定／無効）、対象拡張子、最大探索階層、除外条件、自動更新などを調整できます。保存後はLaunchの完全終了・再起動が必要です。

ファイル索引はPC内のすべてのファイル・フォルダーを無条件に検索する機能ではありません。索引対象ファイルの親フォルダーからフォルダー結果を生成するため、空フォルダーや対象拡張子のファイルがないフォルダーは結果に含まれない場合があります。自動更新設定や走査状況によって結果が最新でない場合もあります。手動更新はタスクトレイから行えます。

配布時の標準設定では起動後300秒待機、更新間隔30分です。間隔0は自動更新モードで常駐起動後の一度のみとなります。既存のユーザー設定が優先されます。索引の現在の稼働状態をより分かりやすく可視化することは今後の課題です。

## 開発用ソースから起動する場合

GitHubのソースから動かす場合は、WindowsにPythonを用意してから開発用の依存パッケージを導入します。**ポータブル配布版とは手順が異なります。**

```bat
py -3.15 --version
update_python_env.bat --no-build
_★run_windows.bat
```

Windows用EXEの作成には `_build_windows.bat` を使用します。新規環境・移行の推奨は標準（非free-threaded）の64bit Python 3.15.2です。既存3.10〜3.14の仮想環境は従来の依存バージョンを維持します。Python更新から再ビルドまで行う場合は `update_python_env.bat` を使用してください。詳細は [Python 3.15移行手順](docs/Python_315_Migration_20261125.md) を参照してください。

開発者向けの `_★release_FRBLaunch_GUI.ps1` では、Launch本体版（`src/app_version.py` の `APP_VERSION`）の更新とEXEビルドを行い、その後、必要に応じて統合版の準備・検証・GitHub公開に進めます。本体版と統合版は独立管理で、ビルドのみでも終了できます。詳細は[リリース管理GUIの技術メモ](docs/release_gui_launch_version_20261127.md)を参照してください。

## メニューはJSONで管理。AI協働にもつながる

FRB Launchのメニュー構成はJSONデータとして管理しています。実際のファイルを移動することなく、**使うための論理的な階層と順序**を組み立てられるのが特徴です。

- 目的別にページ・フォルダー・項目を整理する。
- AIに小さなバッチファイルやスクリプトを作ってもらい、Launchに登録する。
- JSONのメニュー構成をAIに見せて、整理案や追加案を相談する。
- 登録済みのアクションを使いながら、少しずつ便利な道具を増やしていく。

JSONを手書きする必要はありません。配布版に含まれる**FRB Studio**は、Launchの設定エディターとして利用できます。メニューデータと表示定義（ViewDef）を分ける考え方を採用しています。

> **AIを使わなくても便利。AIを使うと、便利さを自分で育てられる。**

**注意：** 設定データにはPC内のパス、URL、コマンド、個人情報が含まれる場合があります。AIサービスへの送信や共有前に、内容を確認してください。登録された外部コマンドは利用者の権限で実行されます。

### 設定ファイルの位置

- メニュー設定のJSON：`frb_launch_data.json`（環境・配布構成によって実際の配置を確認してください）
- 初回起動時の既定設定：`defaults/state.ini`
- ユーザー個別の設定：`%LOCALAPPDATA%\FRBLaunch\state.ini`
- アプリ連携などのユーザー別オプション：`%LOCALAPPDATA%\FRBLaunch\UserConfig\`

初回設定は、既存のユーザー設定がないときに適用されます。既存の設定を勝手に上書きしない設計です。詳しくは[初回設定の技術メモ](docs/FRBLaunch_FirstInstall_StateIni_20261115.md)を参照してください。

## 更新・終了・アンインストール

### 更新

新しい版が公開された場合、更新情報を確認し、**ユーザーが明示的に操作して更新する方式**です。自動的な強制更新ではありません。

- [FRB Launch リリース一覧](https://github.com/tamasub/FRB-Launch/releases)
- 更新前には、メニューJSONやユーザー設定など、大切なデータのバックアップをおすすめします。

### 終了・アンインストール

1. FRB Launchを終了します。Windows起動時の自動起動を有効にしている場合は、先に解除してください。
2. 展開したFRB Launchのフォルダーを削除します。
3. ユーザー設定まで削除したい場合だけ、内容とバックアップを確認して `%LOCALAPPDATA%\FRBLaunch` のデータも削除します。

**フォルダーを削除する前に、保存済みの設定JSONや必要なファイルが含まれていないか確認してください。**
