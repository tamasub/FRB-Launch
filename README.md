## FRB Launchでできること

FRB Launchは、**Windows 11向けの無料ランチャー**です。毎日使うアプリ、フォルダー、ファイル、Webのブックマーク、バッチファイルなどを、ひとつの入口から探して実行できます。

初めての方には、まず**普通に便利なランチャー**として使ってほしい。独自のマウス操作やAIとの連携は、必要になったときに試せる追加の楽しみです。

| できること | 使う人にとってのメリット |
| :-- | :-- |
| 📁 **保存場所と「使うための整理」を分ける** | 元のファイルを移動せず、仕事別・目的別のメニュー階層や並び順を自由に組み立てられる |
| 🚀 **よく使うものを一か所に集める** | アプリ・ファイル・フォルダー・URL・バッチ／スクリプトをまとめて呼び出せる |
| 🖱️ **ドラッグ＆ドロップでかんたん登録** | エクスプローラーのファイル・フォルダーも、Chrome／EdgeのURLも、ドラッグしてLaunchのメニューアイテムに追加できる |
| 🔎 **ごちゃまぜサーチ** | 登録したものを種類の違いを気にせず、ひとつの検索窓から探せる |
| 🧠 **わがままサーチ** | AND・OR・括弧を組み合わせ、探し方を自分で指定できる |
| ⌨️ **キーボードでもマウスでも操作** | 矢印キー・Enter、マウスホイール、クリックなど、好きな方法を選べる |
| 📅 **定型入力・便利なアクション** | 日付やよく使う文章の入力、登録したコマンドの起動など、繰り返し作業を減らせる |
| 🧩 **JSONでメニューを管理** | 設定をデータとして扱え、AIにメニューの整理を相談したり、AIが作った小さなツールを登録したりできる |

> **探す対象はごちゃまぜ。探し方はわがまま。**  
> ごちゃまぜサーチは「何を探すか」、わがままサーチは「どう探すか」を担当します。

※検索の対象や範囲は機能・画面によって異なります。「登録したものを探す機能」が、PC内の全ファイルを無条件に検索するという意味ではありません。

## まずはこんな使い方から

**メニューへの登録は、ドラッグ＆ドロップでもかんたん！**

- **エクスプローラーから**フォルダーやファイルをFRB Launchのメニューへドロップすると、メニューアイテムとして追加できます。

  <img width="300" height="200" alt="image" src="https://github.com/user-attachments/assets/d43eaeab-bb9b-4b09-8ff5-965a96350799" />

- **Chrome／Edgeから**WebページのURLをドラッグしてFRB Launchのメニューへドロップすると、URLのメニューアイテムとして追加できます。

  <img width="300" height="200" alt="image" src="https://github.com/user-attachments/assets/56baae66-ed22-46b2-a898-61141e7386ee" />

ファイルの保存場所やURLそのものを移動する必要はありません。よく使うものへの入口を、Launch側に作れます。

1. 毎日使うアプリ、ファイル、フォルダー、ブックマークを登録する。
2. 保存場所は変えずに、**仕事別・目的別のメニュー**を作る。
3. 検索して選び、Enterやクリックで実行する。
4. もっと楽にしたくなったら、ぐりぐり操作やAIを使ったメニュー整理を試す。

たとえば、AIに作ってもらった日付入力用の小さなスクリプトを登録すれば、日常の操作からすぐに呼び出せます。**AIが作ったものを、毎日の仕事で使う場所までつなぐ**。それが「AI協働を身近にする」の意味です。

## FRB Launch 独自UI機能14選

FRB Launchは、**普通に使える「正統派」**と、少し変わった操作を試す**「革新派」**の両方を育てています。どちらも大切で、機能によっては両方の性格を持ちます。

以下は、[Qiitaで発表した「独自UI機能14選」](https://qiita.com/tamasub/items/659b0b74c5cacbba701f)の名称を残した一覧です。詳しい操作や開発の経緯は記事をご覧ください。**ここに並ぶ機能を覚えないとFRB Launchを使えない、ということではありません。**

| 02 | **FRB ぐりぐり追従スクロール・ハイブリッド方式** | スクロールの端からカレント行の移動へつなぐ |
| 03 | **FRB ぐりぐり追従スクロール・ハイブリッド方式 With 手裏剣スクロール** | ホイールの勢いを慣性滑走・加減速につなぐ |
| 04 | **FRB ぐりぐりクリックRunner** | 右クリックメニューを、ポインターを運ばずに選んで実行 |
| 05 | **FRB ぐりぐりボタンセレクター** | 複数のボタンをホイールで選んでクリック |
| 06 | **FRB 手裏剣メニュー** | フリックして離す操作でメニューを選択 |
| 07 | **FRB かなフリック** | マウスのフリックによる日本語入力の実験 |
| 08 | **FRB ぐりぐりボタン** | ホイールとクリックを集約した、リモコンの操作部 |
| 09 | **FRB Remote（リモコン）** | 小さな場所からLaunchの選択・実行を操作 |
| 10 | **FRB ごちゃまぜサーチ ～ごちゃまぜ整理棚付き～** | 種類を横断して検索し、検索履歴も整理 |

| 12 | **FRB ぱんくず履歴 ～足あと帳付き～** | フォルダー階層の表示と移動履歴を組み合わせる |
| 13 | **FRB Files Exp** | フォルダーとLaunchのメニューをたどるツリービュー |

### 14選には収まらなかった「おまけ」

14選はそのままに、便利な機能や新しい実験も増えています（笑）。

- **おまけ① Browser**：Webページやブックマークも、Launchでの作業の流れに取り込めます。
- **おまけ② FRB わがままサーチ**：AND・OR・括弧で条件を組み立てます。なお、**「超わがままサーチ」はFRB Studio側の別機能**です。
- **おまけ③ ぐりぐりボタン（単独リモコン）**：**v0.9.11で追加**。Files ExpとFiles Listの境界に、直径60pxの丸い操作ボタンを表示します。

### おまけ③：小さな丸ボタンでExpとListを操作する

　　<img width="400" height="300" alt="image" src="https://github.com/user-attachments/assets/46166568-37c3-43c6-95c6-8446a962ae63" />


丸ボタンの**左半分にポインターを置くとFiles Exp、右半分ならFiles List**が操作対象になります。ボタンの上でホイールを回して対象を選び、クリック・ダブルクリック・右クリックと組み合わせて操作できます。

**マウスポインター自動移動がON**なら、対応する列切替操作の際にも、丸ボタン内の次の操作位置へポインターを移動させられます。自動移動はOFFにできます。

> **操作対象は広く、操作する場所は狭く。**

この機能は、ゆっくりと楽に操作した向けの機能です。操作スピードは追求していません。

この方式はFRB Launch内のFiles画面向けです。**Windows標準のエクスプローラーや他のアプリを丸ボタンから一律に操作できる、という意味ではありません。**

## はじめ方

### 動作環境・配布状況

- **Windows 11（64-bit / x64）** を対象に公開しています。
- 利用料金は**無料**です。
- 一般環境での動作や品質が十分に検証済みという意味ではありません。
- ポータブル配布版には実行に必要な環境が含まれ、通常利用でPythonやNode.jsの個別インストールは不要です。
- Windows 10以前やWindows on ARMは動作保証対象外です。

### ダウンロードして起動する

**[FRB Launch vX.X.XX — GitHub Releases](https://github.com/tamasub/FRB-Launch/releases/)**

1. `FRBLaunch_X.X.XX_portable.zip` をダウンロードします。
2. ZIPを任意のフォルダーへ**すべて展開**します。ZIP内から直接EXEを起動しないでください。
3. 展開先にある `FRBLaunch.exe` を起動します。
4. **デスクトップの空き領域をダブルクリック**するとLaunchを呼び出せます。`Ctrl + Shift + ;` でも呼び出せます。
5. 画面右上の**歯車アイコン**から、お好みの表示・操作方法を設定してください。

初回はWindowsのセキュリティ確認画面が表示される場合があります。配布元とファイルを確認してから実行し、セキュリティ機能を無効化しないでください。

### 基本操作

| 操作 | 内容 |
| :-- | :-- |
| デスクトップの空き領域をダブルクリック | Launch画面を呼び出す |
| `Ctrl + Shift + ;` | Launchを呼び出す（設定・キーボード環境によって調整可能） |
| 矢印キー | メニューや階層を移動 |
| `Enter` | 選択項目を実行 |
| `Ctrl + F` | 検索へ移動 |
| マウスホイール | 対応画面でスクロール・選択 |
| Files Listの対応する余白をダブルクリック | 「とんとん親帰り」で親フォルダーへ |

画面や設定によって使える操作は異なります。通常のマウス・キーボード操作を基本とし、独自操作は必要に応じて使えます。

### キーボード操作まとめ（2026年11月24日・開発版）

> ここに記載した新しい操作は**2026年11月24日時点の開発版**を基準としています。最新版への反映を保証するものではありません。操作対象が「Files画面」などに限定される項目もあります。

| キー                            | 対象                    | 動作                                      |
| :---------------------------- | :-------------------- | :-------------------------------------- |
| `Ctrl + Shift + ;`            | Launch全体              | Launchを呼び出す（初期設定。変更可能）                  |
| `Home`                        | Files画面               | 画面上のHOMEボタンと同じ処理。Exp先頭行にフォーカスし、`↓`で選択開始 |
| `Ctrl + F`                    | Files画面               | メイン検索にフォーカス。`↓`で検索履歴を表示                 |
| `Ctrl + G`                    | Files画面               | パンくずの保存フォルダー履歴へフォーカス。`↓`で履歴を表示          |
| `Ctrl + H`                    | Files画面               | Files List側のフォルダー検索にフォーカス。`↓`で検索履歴を表示   |
| `Ctrl + I`                    | Files画面               | 歯車ボタンと同じ設定コンテキストメニューを表示                 |
| `Tab` / `Shift + Tab`         | Files画面               | 下記6地点を正順／逆順に巡回。Filesタブ自体は巡回しない          |
| `↓`                           | Exp／List              | フォーカス後にフォルダー／ファイル行の選択を開始                |
| `↓`                           | 各検索・パンくず              | 履歴を表示。その後の`↑↓`で履歴項目を移動、`Enter`で適用       |
| `→`                           | Files List            | 選択行の右クリックと同じコンテキストメニューを開く（即実行はしない）      |
| `↑↓ / → / ← / Enter / Esc`    | コンテキストメニュー（設定メニューを含む） | 項目移動／子メニューへ／親へ／実行／閉じる                   |
| `PageDown` 4連打 / `PageUp` 4連打 | Files List            | 同方向の4連打で**キーボード手裏剣スクロール**（慣性滑走）を開始      |
| `↑` / `↓`                     | 滑走中のFiles List        | 滑走方向と同じ矢印で加速、逆方向で減速（連打が累積）              |
| `Space` / `Esc`               | 滑走中のFiles List        | 滑走を停止して着地。通常時のSpace操作はそのまま              |
| `PageUp`（単独）                  | Files List先頭          | 従来どおり親フォルダーへ（連打の滑走判定中は誤移動を抑制）           |
| `Enter`                       | Browserタブにフォーカス       | Browserへ切り替える                           |

**Tabの巡回順：** `Exp → List → フォルダー検索 → パンくず履歴 → メイン検索 → Browserタブ → Exp…`。各地点へTabで移動した直後に`↓`を押すと、Exp/Listでは行選択、検索系では履歴表示を始められます。Browserタブでは`Enter`で開きます。

**手裏剣スクロール：** Listにフォーカスした状態で、同じ向きの`PageUp`または`PageDown`を**4連打**すると、既存のマウス手裏剣スクロールと同じ滑走エンジンで移動します。1～3打目は通常のページ移動、4打目で滑走開始。キーの押しっぱなしによる自動リピートは4連打として扱いません。上端・下端では無理に滑走しません。

**Gitコミット先の選択ダイアログ：** 開いた直後はコミット先の選択にフォーカスし、ぐりぐりでリポジトリを変更します。余白クリックでOK/Cancelの選択へ切り替え、ぐりぐりでボタンを選びます。**実際のOK/Cancelボタンは通常のマウスクリックで直接操作可能**であり、余白クリックだけではコミットしません。コミット確定前には別途確認画面が表示されます。

### ぐりぐりボタン・ポインター自動移動は任意

歯車メニューの**「リモコン表示」**は3択です。

| 設定 | 内容 |
| :-- | :-- |
| **使用しない** | **初期値**。標準的な操作で使う |
| リモコンウィンドウ 別Window | 独立ウィンドウとして表示 |
| ぐりぐりボタンのみ | Files Exp / Files Listの境界に丸ボタンを表示 |

**マウスポインター自動移動も初期OFF**です。気に入った方だけONにしてください。自動移動が難しい仮想デスクトップ・リモート環境ではOFFでの使用をおすすめします。

### 開発用ソースから起動する場合

GitHubのソースから動かす場合は、WindowsにPythonを用意してから開発用の依存パッケージを導入します。**ポータブル配布版とは手順が異なります。**

```bat
py -3.15 --version
update_python_env.bat --no-build
_★run_windows.bat
```

Windows用EXEの作成には `_build_windows.bat` を使用します。新規環境・移行の推奨は標準（非free-threaded）の64bit Python 3.15.2です。既存3.10〜3.14の仮想環境は従来の依存バージョンを維持します。Python更新から再ビルドまで行う場合は `update_python_env.bat` を使用してください。詳細は [Python 3.15移行手順](docs/Python_315_Migration_20261125.md) を参照してください。

## メニューはJSONで管理。AI協働にもつながる

FRB Launchのメニュー構成はJSONデータとして管理しています。実際のファイルを移動することなく、**使うための論理的な階層と順序**を組み立てられるのが特徴です。

- 目的別にページ・フォルダー・項目を整理する。
- AIに小さなバッチファイルやスクリプトを作ってもらい、Launchに登録する。
- JSONのメニュー構成をAIに見せて、整理案や追加案を相談する。
- 登録済みのアクションを使いながら、少しずつ便利な道具を増やしていく。

JSONを手書きする必要はありません。配布版に含まれる**FRB Studio**は、Launchの設定エディターとして利用できます。メニューデータと表示定義（ViewDef）を分ける考え方を採用しています。

> **AIを使わなくても便利。AIを使うと、便利さを自分で育てられる。**

**注意：** 設定データにはPC内のパス、URL、コマンド、個人情報が含まれる場合があります。AIサービスへの送信や共有前に、内容を確認してください。登録された外部コマンドは利用者の権限で実行されます。

### 設定ファイルの位置

- メニュー設定のJSON：`config/frb_launch_data.json`（環境・配布構成によって配置を確認してください）
- 初回起動時の既定設定：`defaults/state.ini`
- ユーザー個別の設定：`%LOCALAPPDATA%\FRBLaunch\state.ini`

初回設定は、既存のユーザー設定がないときに適用されます。既存の設定を勝手に上書きしない設計です。詳しくは[初回設定の技術メモ](docs/FRBLaunch_FirstInstall_StateIni_20261115.md)を参照してください。

## 更新・終了・アンインストール

### 更新

新しい版が公開された場合、更新情報を確認し、**ユーザーが明示的に操作して更新する方式**です。自動的な強制更新ではありません。

- [FRB Launch リリース一覧](https://github.com/tamasub/FRB-Launch/releases)
- 更新前には、メニューJSONやユーザー設定など、大切なデータのバックアップをおすすめします。

### 終了・アンインストール

1. FRB Launchを終了します。Windows起動時の自動起動を有効にしている場合は、先に解除してください。
2. 展開したFRB Launchのフォルダーを削除します。
3. ユーザー設定まで削除したい場合だけ、内容とバックアップを確認して `%LOCALAPPDATA%\FRBLaunch` のデータも削除します。

**フォルダーを削除する前に、保存済みの設定JSONや必要なファイルが含まれていないか確認してください。**

### FRBとは？

**FRB = Fishing Rod Benchmark**。釣り竿の「感度」を振動から捉え、比較できるようにする個人研究から始まった名前です。

釣り竿でもソフトウェアでも大切にしているのは、**人間が感じた小さな違いを見逃さないこと**。

[FRB研究（GitHub）](https://github.com/tamasub/FRB) ／ [FRBの紹介](https://tamasub.github.io/FRB/)

## 2026-11-21 — Ctrl+Gぱんくず履歴と第3列エディター設定

- Ctrl+G後、独立した非アクティブ化ToolへQtフォーカスを渡す方式を廃止し、Launch側のキー入力を表示中の履歴へ明示的にルーティング。↑/↓/Enter/→/Delete/Escを処理。
- `defaults/state.ini` の初回標準値: `embed_studio=true`, `embed_obsidian=true`, `embed_vscode=true`, `embed_sakura=true`。Studio以外はオプション設定「アプリ連携」で変更でき、保存先はUserConfig/app_embedding_options.jsonです（初回設定画面で旧state.iniから引き継ぎ、再起動後に反映）。Studioは引き続きUserのstate.iniを参照し、旧ファイルは上書きしません。
- Sakuraは引き続き第3列ゲストを無効（通常のエディター外部起動は変更なし）。
- 既存インストールでは `%LOCALAPPDATA%\FRBLaunch\state.ini` の `[General]` を手動更新してください（詳細は docs/FRBLaunch_FirstInstall_StateIni_20261115.md）。
