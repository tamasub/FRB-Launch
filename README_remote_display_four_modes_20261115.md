# FRB Launch — リモコン表示4択 / ぐりぐり丸ボタン（2026-11-15）

## 対象と適用

ベース: `launch_app_20261115_205519.zip`（20:55版）。差分ZIPは元ソースのルートに上書き展開してください。

## リモコン表示（設定メニュー）

「リモコン表示」サブメニューは**排他的な4択**です。

- **使用しない** (`off`) — 初期値。リモコンを表示しない
- **リモコンウィンドウ 1.5列へ表示** (`column15`) — 従来の1.5列配置
- **リモコンウィンドウ 別Window** (`window`) — 従来の独立したリモコン
- **ぐりぐりボタンのみ** (`wheel`) — FilesのExp/List境界に小さい円形WheelPadを表示

設定は `%LOCALAPPDATA%\FRBLaunch\state.ini` の `[General]` 内の `remote_display_mode` に保存します。`defaults/state.ini` は新規インストール時のみ参照され、初期値は `off` です。既存state.iniの `desktop_remote_enabled` / `experiment_remote_15_column` しかない環境は、旧1.5列→`column15`、旧リモコンON→`window`、その他→`off` の順に読み替えます。新しい選択後は旧2キーも同時更新します。

## 丸いぐりぐりボタン

- **ボタン自体が直径52pxの丸型**（文字の「〇」を置いただけではありません）
- **本体内の子Widget**として配置。別Windowは作成しません
- Files Exp/Listの分割バー中央に配置。Windowsのウィンドウ移動時は親に追従
- Expの幅変更、Launchのリサイズでも再位置決め
- Browserモード、他3モードでは非表示
- 既存`WheelPad`のホイール・クリック・ダブルクリック・長押しによるターゲット選択を再利用し、既存の`remote_command`へ接続
- 右クリックは丸ボタンから既存のリモコン操作対象コンテキストメニューへ接続
- いまのExp/List操作対象を保持。ボタン表示だけで勝手にカレント行を変更しません

## Windowsでの確認手順

1. `FRB_Launch`の**ソースフォルダー**に差分ZIPを上書き展開する（ポータブル配布のexeフォルダーではありません）。
2. `_run_windows.bat` で起動する。
3. 設定 → リモコン表示 → `ぐりぐりボタンのみ` を選択。Exp/List境界付近に円形ボタンが出る。
4. ボタン上でぐりぐり、クリック、ダブルクリック、右クリックを試す。
5. Launchウィンドウの移動・拡大縮小、Files Exp幅のドラッグ変更で追従することを確認する。
6. `使用しない` に戻すと消え、`別Window`・`1.5列` に切り替えると各々の従来モードとなることを確認する。
7. Launch再起動後も選択したモードが維持されることを確認する。

### 検証上の制限

Python構文確認とQtに依存しない設定契約・ソース接続テストは通過しました。**Windows/PySide6実機の表示・マウス入力動作はこの環境では未検証**です。丸ボタンの細かなデザイン位置やイベント伝播は実機検証で微調整が必要な可能性があります。
